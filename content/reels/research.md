## Temas

Cada tema sale de una línea de `projects.js`. La necesidad está citada del repo; la palabra clave es una **hipótesis** a validar.

### 1. Diseño web / página web para negocio

- **Necesidad (servicios.js):** "La mayoría de las páginas no pierden clientes por feas. Los pierden porque tardan en abrir, porque en el teléfono hay que hacer zoom para leer, o porque el visitante llega buscando un precio, un horario o un número de WhatsApp y tiene que adivinar dónde está."
- **Contexto local:** "Aquí la mayoría del tráfico llega desde un teléfono y con datos móviles"; "En Honduras el primer contacto casi nunca es un formulario: es un mensaje de WhatsApp."
- **Demos:** landing (`demos/landing/`: Velora, Nexora, Órbita), Aurelis.
- **Palabras clave candidatas:** página web Honduras · diseño de páginas web en Honduras · página web con WhatsApp · desarrollo web Tegucigalpa.
- **Patrones de hook a probar:** error caro ("Tu página te está costando clientes"), pregunta de dolor ("¿Tus clientes no saben cómo contactarte?"), objeción ("No necesitas WordPress").
- Hooks outlier encontrados: _pendiente de vidIQ_.
